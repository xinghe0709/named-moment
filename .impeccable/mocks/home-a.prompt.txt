Use case: ui-mockup
Asset type: high-fidelity desktop web application north-star comp, 1440×1024 landscape
Primary request: Design the first viewport of the Chinese web product “此刻有名”, where a person writes an emotionally difficult-to-name moment and an AI later matches it to three real sourced words from world languages. This is an integrated Spring Boot MVP, but the image must look like a finished consumer product, not a developer dashboard.
Surface structure: no conventional hero banner and no sidebar. Build the whole viewport as a steel-framed hand-rolled glass partition. A slim top glazing bar contains the brand “此刻有名” on the left and the text link “私人档案馆” on the right. Below it, one dominant clear seeded-glass pane occupies about two-thirds of the viewport and contains the large prompt “告诉我一个你无法解释的瞬间。” plus a generous transparent writing area with placeholder “写下一段日记、一个念头，或刚刚发生的事……”. The primary action “为此刻寻找名字” is physically integrated into the lower black mullion, not a floating rounded button. The right third contains two quiet unequal panes: one with the promise “原来我的这种感觉，在世界上的某个角落早就有人给它取过名字。” and one small cobalt backlit pane showing “真实概念 · 可靠来源 · 三个答案”. A small privacy note says “只保存在你的私人档案馆”. Show a hint of the next glass bay below the fold so the system can continue.
Style/medium: exact polished UI/UX mockup, front-on architectural elevation, quiet contemporary glazier workshop, crisp semantic interface, no people and no photography. The main interaction must be unmistakably a textarea and button.
Typography: confident humanist grotesque, Chinese text perfectly legible, large scale contrast, no all-caps micro labels, no monospace decoration, no display serif.
Color palette: matte mullion black #171918, seeded glass white #E9ECE7, cool atmospheric glass #C9D6D3, one memory cobalt #1646B8, tiny restrained amber #F2A93B only as a status glint. No beige, terracotta, neon, purple, or gradients.
Materials/textures: subtle watery seeded-glass distortion inside panes, true 5–7px black glazing bars, restrained diffuse backlight, almost flat; no glassmorphism cards, no drop-shadow card stack.
Composition/framing: straight-on browser viewport only, full bleed, strong asymmetric grid, generous quiet space, readable at first glance.
Text (verbatim): “此刻有名” “私人档案馆” “告诉我一个你无法解释的瞬间。” “写下一段日记、一个念头，或刚刚发生的事……” “为此刻寻找名字” “原来我的这种感觉，在世界上的某个角落早就有人给它取过名字。” “真实概念 · 可靠来源 · 三个答案” “只保存在你的私人档案馆”
Constraints: interface only, desktop web viewport, no browser chrome, no mock device frame, no invented statistics, no testimonials, no extra navigation, no generic cards, no rounded rectangles, no pill buttons, no excessive icons, no decorative arrows, no lorem ipsum, no watermark.
