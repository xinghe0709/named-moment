# Asset Manifest

## `src/main/resources/static/assets/seeded-glass.png`

- **Dimensions:** 2048 × 2048 px, PNG
- **Purpose:** Subtle, neutral-cool hand-rolled seeded-glass texture for a full-page CSS background overlay. Its low-contrast, edge-to-edge material field supports either cover scaling or repeated tiling without an obvious seam.
- **Provenance:** Generated with the built-in OpenAI ImageGen workflow from an asset-specific prompt derived from the approved `home-b-approved.png` north-star comp and its exact `home-b-approved.prompt.txt` brief. The exact asset-generation prompt is embedded in the PNG under the `impeccable:prompt` metadata key using Impeccable's `embed-prompt.mjs` script. The source generation was 1254 × 1254 px and was resized once to 2048 × 2048 px with Lanczos resampling for production use.
- **Semantic code remains responsible for:** All product text and typography; steel mullions and glazing bars; cobalt, amber, clear, and frosted pane colors; textarea and action controls; focus, hover, loading, error, and other interaction states; layout and responsive behavior; borders, shadows, and depth effects. None of those elements are baked into this raster.
