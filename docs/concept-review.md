# 「此刻有名」概念库复核记录

## 证据基线

- 主来源：[Positive Lexicography 交互词库](https://hifisamurai.github.io/lexicography/)。它由 Tim Lomas 负责内容与研究，并从[研究者官网](https://www.drtimlomas.com/lexicography/cm4mi)直接链接。
- 研究背景：[Towards a positive cross-cultural lexicography](https://doi.org/10.1080/17439760.2015.1127993)。该同行评审论文说明了跨文化幸福与情感词汇的整理方法。
- 每个入库项均在交互词库中检索到对应名称、语言和英文释义；中文 `meaning` 与 `description` 是面向产品场景的简短转述，不是原文翻译。
- 复核编号按 `data.sql` 顺序记录，不等同于数据库自增 ID。交互词库属于持续更新的学术策展项目；正式上线前仍可把高频命中项升级为语言权威词典链接。
